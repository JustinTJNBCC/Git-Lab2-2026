# Password Reset Procedure

## Current Revision

Document Owner: Help Desk Team
Last Updated: September 2026
Priority: Standard

## Standard Reset Process

1. Verify the user's identity.
2. Locate the user account.
3. If it doesn't exist return a reasonable error message
4. Generate a temporary password.
5. Require password change at next login.

## Escalation

Users should contact IT support if they experience account issues.
